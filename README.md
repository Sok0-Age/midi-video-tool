# midi-video-tool
MIDIから音合わせ動画を作るツールです。
スマートフォン等デバイスでの音MAD・YTPMV等の作成向けですが工夫すれば他のことにも使えそう？

## 使い方
1. MIDIファイルをアップロード
2. 使いたいトラックを選択
3. 動画ファイルをアップロード
4. モードを選択して「動画を生成」

## モードの詳細
### 左右反転モード
「毎ノート交互に反転・反転しない・全ノート反転・ランダム反転」から選べます

### 映像繰り返しモード
「1音ごとに映像を繰り返す・映像を終わるまで再生する」から選べます

前者は普通の音MADの左右反転みたいに音ごとに映像を頭から再生し、後者は映像を繰り返さず左右反転のみ行います（https://www.nicovideo.jp/watch/sm37317836 みたいな感じです）

（その特性上、反転しない/全ノート反転と同時に使うと無意味な動画が生成されます）

### 最後のノートの長さ調整
最後の音はしばらく余韻があった方が使いやすそうなので調整できるようにしています

## 注意
- 生成された動画に音声は含まれません
- 動画はMP4推奨
